# Автоматизация тестирования API
Выполни практическое задание по материалам курса и примени основные подходы к автоматизации тестирования REST API: разработай набор API-тестов для проверки позитивных и негативных сценариев, граничных значений и валидации, используй спецификацию OpenAPI для генерации тестов или реализуй контрактное тестирование между двумя сервисами.


## Цель:
Сформировать практические навыки разработки автоматизированных тестов для REST API, применения контрактного тестирования, использования спецификаций OpenAPI и интеграции API-тестов в процесс разработки программного обеспечения.*

## Задание:
На выбор: написать тесты для REST API (public API или mock), минимум 5–7 тестов (positive/negative, границы, валидация); сгенерировать OpenAPI-спецификацию и использовать её для генерации тестов; реализовать contract testing между двумя сервисами (mock + real) с описанием проверяемых контрактов. Работа ведётся в открытом GitHub-репозитории в ветке homework-<n> с ревью и исправлениями через pull request.

## Критерии оценивания (max. 10 б.):
Критерии оценивания: Корректность и полнота тестов, использование контрактов/OpenAPI, оформление репозитория и прохождение ревью — 10 баллов.

Срок выполнения: 2 недели

Критерии оценки: оцениваются корректность и полнота тестов, использование контрактов и OpenAPI, качество оформления репозитория, а также прохождение ревью и внесение необходимых исправлений.
